Este repositório tem como objetivo criar uma página com a **pior UX possível**, para obtenção de nota na matéria de Projeto e Desenvolvimento de Sistemas.

## Como abrir

Abra `index.html` no navegador (não precisa de servidor, mas cookies/sessionStorage funcionam melhor em `http://localhost`).

## Fluxo (de propósito hostil)

1. **Início** (`index.html`) — popups de cookie/Java, botões que fogem, labels invertidos, 40% de chance do botão certo funcionar. O atalho real está em 5px no rodapé.
2. **CAPTCHA** (`CAPTCHA.html`) — conta com palavras ao contrário, resposta numérica **com espaço no final**, regenera a cada 12s, exige duas tentativas “quase”.
3. **Login** (`login.html`) — campos e-mail/senha trocados, confirmação deve ser *diferente*, termos desmarcam sozinhos, botão **Voltar** entra e **Entrar** limpa. Sessão expira.
4. **Painel** (`painel.html`) — cartões com destinos aleatórios. Links minúsculos levam aos formulários certos.
5. **CPF / CNPJ / Dados** — validação capciosa, ordem de tab invertida, select gigante, slider inútil.
6. **Protocolo** (`protocolo.html`) — “sucesso” invertido, número de cabeça para baixo, não copia.
7. **Termos / Ajuda** — rolagem invalida a leitura; acessibilidade em 4px com A+ diminuindo a fonte.

Tudo é fictício. Nenhum dado é enviado a servidor.
